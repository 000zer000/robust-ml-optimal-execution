Read the result correctly

Lower cost is better; zero is the 100-tick arrival reference. Cost = (paid quote atoms - 100 * 100) / (100 * 100) * 10,000. For the first past-volume path, 10*101 + 20*100 + 30*99 + 40*100 = 9,980, hence -20 bps.

This teaching settlement assumes sufficient available quantity and immediate fills at each specified ask, zero fees and zero latency. It omits queue uncertainty and impact. It is not a full matching-engine strategy replay. The matching-engine demonstration runs separately and checks price-time priority, replacements, cancellation and invariants.

Historical Gate C remains closed. No historical profitability, learned strategy advantage, live execution or GPU performance is established by these examples.
