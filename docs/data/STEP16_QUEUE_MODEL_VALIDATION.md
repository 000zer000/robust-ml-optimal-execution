# Step 16 queue-model validation protocol

## Required gates

1. Frozen specification hashes remain unchanged.
2. Optimistic, central, and pessimistic models share all behavior except unexplained cancellation allocation.
3. A level reduction following a trade cannot double count the same depletion.
4. Cancellation-only sequences cannot produce fills.
5. Trade-through fills the residual passive child when enabled.
6. Exact synthetic FIFO fills are generated by the price-time-priority matching engine.
7. Exact fills are bounded by optimistic and pessimistic estimates in every committed comparison scenario.
8. Model estimates are ordered optimistic ≥ central ≥ pessimistic in every committed scenario.
9. Hidden-ahead sensitivity is directionally monotonic.
10. C++ and Python evidence is deterministic and hash verified.
11. Historical exact-FIFO reconstruction remains explicitly false.

## Deterministic scenarios

| Scenario | Purpose |
|---|---|
| `no_cancellation` | Verify all models agree when only an at-price trade determines the fill. |
| `cancellation_ahead` | Exact FIFO receives a large cancellation ahead; optimistic should be closest or equal. |
| `cancellation_behind` | Exact FIFO receives cancellation behind; pessimistic should be closest or equal. |
| `mixed_cancellation` | Central proportional allocation is tested against a 50/50 ahead/behind exact case. |
| `addition_only` | New displayed quantity behind the child must not improve queue position. |

The exact scenarios are deliberately diagnostic. They do not constitute calibration to Binance or evidence that the central model is empirically best.

## Evidence artifacts

- `report.json`: canonical C++ validation result;
- `scenario-comparison.csv`: exact-versus-model matrix;
- `sensitivity.csv`: assumption × hidden-ahead matrix;
- `manifest.json`: immutable hashes and non-research classification.

The validator independently checks JSON Schemas, artifact hashes, required scenario identities, model ordering, exact-fill bounds, sensitivity monotonicity, and deterministic regeneration.
