# Validation Ledger

This directory preserves the staged changelogs, validation reports, and artifact manifests created
during development. They are retained as provenance: a reviewer can trace when a capability was
introduced, what was checked, and which files were covered by its recorded hashes.

These records are not the recommended starting point for the project. Use the root
[README](../../README.md), the [professor review guide](../../docs/research/PROFESSOR_REVIEW_GUIDE.md),
the [research paper](../../paper/Robust_ML_Optimal_Execution_Research_Paper.pdf), and the
[claim-traceability table](../../paper/CLAIM_TRACEABILITY.md) first.

The active release manifests for Steps 25–30 are checked by the repository validators. Earlier
records are historical snapshots and should be interpreted in the context of the release at which
they were produced. Moving the ledger here changes only repository organization, not experimental
results or scientific claims.
